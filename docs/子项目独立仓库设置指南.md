### 3. 创建 README 文件

为每个子项目创建说明文档：

#### Backend README.md

```markdown
# VPN Service Backend

## 📋 概述

VPN 服务的后端服务，基于 NestJS 框架开发。

## 🛠 技术栈

- **框架**: NestJS ^10.0.0
- **数据库**: PostgreSQL ^14
- **缓存**: Redis ^7
- **ORM**: TypeORM ^0.3.0
- **认证**: JWT
- **开发工具**: TypeScript, ESLint

## 📦 功能特性

- 用户认证与授权
- VPN节点管理 (VLESS、VMess、Trojan等协议)
- 节点延迟检测
- VPN连接与断开
- 订阅套餐管理
- 订单系统
- 支付集成 (支付宝、微信支付)
- 流量统计与监控
- 连接日志记录
- 管理后台功能
- 系统日志管理

## 🚀 快速开始

### 前置要求

- Node.js >= 18.0.0
- npm >= 9.0.0
- PostgreSQL >= 14
- Redis >= 7

### 安装

```bash
# 安装依赖
npm install

# 配置环境变量
cp .env.example .env
# 编辑 .env 文件

# 运行数据库迁移
npx typeorm migration:run

# 运行种子数据
npx ts-node seed.ts

# 启动服务
npm run dev
```

详细的 API 文档请查看 `docs/api/` 目录。
